# IFIT V0.7.1 — EVENT MEMORY & ALERT ENGINE

Builds on V0.7.0 with persistent in-session event memory and ranked alerts.

Features:
- NEW / ONGOING / RESOLVED event states
- Persistent current-session event memory
- Alert priority ranking
- Highest-priority IFIT Market Alert
- Active alert ranking table
- Resolved event history
- Occurrence counting
- Alert summary
- Transparent methodology

The engine is diagnostic/research intelligence. It does not send external
notifications or place orders.
