# IFIT V0.7.6 — Liquidity & Execution Engine

Adds an explainable liquidity and execution diagnostic layer to the IFIT market stack.

## Features
- Normalized bid/ask spread diagnostics
- Provider quote support when bid/ask fields are present
- Five-level depth support when provider depth fields are present
- Conservative OI-based depth proxy in simulation mode
- Liquidity Score (0–100)
- Execution Risk score
- Liquidity regimes: DEEP / EFFICIENT, HEALTHY, SELECTIVE, THIN, FRAGILE
- Highest-quality contract map
- Lowest-quality execution-risk map
- ATM execution ladder for 1 / 5 / 10 lots
- Spread in basis points
- Estimated slippage per point and rupee impact
- Top-depth and five-level depth utilization
- Transparent methodology and data-source labels

## Important limitation
Simulation mode does not have a real order book. OI-derived depth is explicitly a proxy and is not executable liquidity. Production execution analytics should use an authorized market-data/order-book provider.
