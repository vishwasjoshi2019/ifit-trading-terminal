# IFIT V0.8.2 — Terminal Navigation & Workspace Engine

## Objective
Turn the V0.8.1 terminal shell into a persistent workspace/navigation layer without changing the underlying quantitative engines.

## Delivered
- Persistent terminal workspace state across Streamlit reruns.
- Eight top-level workspaces: Command Center, Markets, Equities, Options, Charts, Portfolio, Risk Engine, AI Intelligence.
- Module-specific subview routing.
- Shared instrument context (NIFTY 50 / BANK NIFTY / SENSEX) and timeframe context.
- Shared data-mode/status context tied to the active data-health snapshot.
- Compact top navigation rail plus sidebar workspace navigation.
- New `engines/workspace_engine.py` containing pure workspace configuration/state helpers.
- Existing V0.8.0 intelligence engines remain reusable and unchanged in their core logic.

## Safety / data disclosure
The simulator remains the default. Live market data requires an authorized broker, exchange feed, or licensed data vendor. Workspace context does not create or imply trading signals.
