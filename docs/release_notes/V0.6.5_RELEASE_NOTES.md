# IFIT V0.6.5 — LIVE MODEL DISLOCATION INTELLIGENCE

Adds an explainable contract-level model-dislocation layer on top of V0.6.4.

Features:
- Market IV vs Heston IV residuals
- Price residuals
- Higher-order Greek sensitivity contribution
- Expiry sensitivity
- Calibration-quality confidence
- 0–100 dislocation score
- NORMAL / WATCH / ELEVATED / EXTREME regimes
- Primary and secondary driver attribution
- Top-dislocation contract panel
- Calibration-quality classification

The score is a research/model diagnostic, not an automatic arbitrage or trade signal.
