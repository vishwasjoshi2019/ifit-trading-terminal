# IFIT V0.7.0 — REAL-TIME EVENT ENGINE

Adds the change-detection/event layer on top of the V0.6.x intelligence stack.

Detects:
- Signal shifts
- Regime transitions
- Flow regime changes and acceleration
- Volatility regime changes and shifts
- Gamma risk shifts
- Model dislocation shifts
- Expected-move breaches
- Support/resistance breaks
- Data-health transitions

UI:
- Current Event Watchlist
- IFIT Event Timeline
- Event severity and score
- Transparent methodology

The first run establishes a baseline. Subsequent refreshes compare the prior
session state with the current state. Events are research diagnostics, not
automatic trading instructions.
