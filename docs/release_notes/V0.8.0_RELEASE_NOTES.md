# IFIT V0.8.0 — CONSOLIDATED INTELLIGENCE TERMINAL

## Purpose
V0.8.0 consolidates the IFIT V0.6.7–V0.7.7 intelligence stack into a single command-center view.

## Included layers
- Market Intelligence
- Regime Engine
- Signal Engine
- Event / alert context
- Decision Matrix
- Scenario / stress engine
- Risk Engine
- Portfolio Risk
- Liquidity & Execution
- Market Microstructure
- Volatility / model diagnostics

## New command center
The default module is now **IFIT Command Center**. It provides:
- IFIT Score
- Operating State
- Direction + conviction
- Executive confidence
- Market / regime / flow / volatility map
- Decision Matrix
- Risk & execution dashboard
- Evidence Ladder
- Stress & tail map
- Key levels
- Execution impact
- Portfolio risk snapshot
- Methodology / architecture disclosure

## Data policy
Simulation/proxy data remains explicitly labelled. Production deployment should use synchronized data from an authorized NSE feed, broker API, or authorized data vendor. No NSE webpage scraping is used.

## Research boundary
V0.8.0 is decision-support research software. Scores are normalized diagnostics and are not probabilities of profit, VaR, margin requirements, guaranteed fills, or automatic trading instructions.
