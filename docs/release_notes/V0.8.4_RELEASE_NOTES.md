# IFIT V0.8.4 — Advanced Interactive Chart Engine

- TradingView-style interactive Plotly chart workspace.
- Candlestick, Line and Area views.
- Multi-indicator stack: EMA, SMA, VWAP, Bollinger Bands, Supertrend, RSI, MACD, ATR, Volume, CVD and Delta.
- Configurable indicator parameters.
- Lower indicator panes with synchronized crosshair/hover.
- Native chart drawing tools: line, open path, rectangle, circle and erase.
- IFIT POC and optional Volume Profile overlay.
- Explicit simulation/proxy labelling retained.
- No order placement logic.
- Saved chart templates are intentionally deferred to the next layer.
