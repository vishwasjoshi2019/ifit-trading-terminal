# IFIT V0.8.3 — Professional Charts Workspace

V0.8.3 turns the Charts terminal module into a dedicated professional research workspace while preserving the V0.8.2 terminal architecture.

## Added
- Professional OHLC candle workspace
- Timeframe selector: Intraday, 5 min, 15 min, 1 hour, Daily
- Bar-count selector
- VWAP overlay
- POC and 70% value-area profile
- Volume Profile workspace
- CVD and per-bar Delta workspace
- Normalized Price vs CVD comparison
- Existing footprint ladder surfaced as a dedicated view
- Microstructure view using the V0.7.7 execution/microstructure engine
- Shared terminal instrument/data context retained
- Explicit simulation/proxy labelling
- Charts methodology panel

## Data Integrity
V0.8.3 does not scrape exchange webpages and does not create automatic orders. Provider quote/depth fields are preferred when available; simulation/proxy values remain labelled until an authorized feed is connected.
