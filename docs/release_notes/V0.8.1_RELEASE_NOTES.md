# IFIT V0.8.1 — Terminal Architecture

## Objective
Turn the V0.8.0 consolidated intelligence prototype into the first true IFIT terminal shell.

## Added
- Terminal-level navigation: Command Center, Markets, Equities, Options, Charts, Portfolio, Risk Engine, AI Intelligence.
- Persistent terminal header/workspace indicator.
- Markets workspace with market state, PCR, IV-HV, flow, volatility and model-dislocation map.
- Equities workspace scaffold for fundamentals, valuation, quality, growth, peers and scoring.
- Options workspace with professional option chain, IV smile, gamma and expected move.
- Charts workspace with candles/volume, footprint/delta and CVD/POC/value-area views.
- Portfolio workspace connected to existing V0.7.5 portfolio risk engine.
- Risk Engine workspace connected to existing V0.7.4 cross-engine risk diagnostics.
- AI Intelligence workspace with grounded snapshot prototype; no external AI call or order placement.
- Global Data Health Monitor and terminal architecture status table.

## Architecture principle
V0.8.1 is a shell/orchestration release. Existing quantitative engines remain modular underneath the terminal. Simulation/proxy data is explicitly labelled until an authorized market-data/depth provider is connected.
