# IFIT V0.6.6 — LIVE VOLATILITY SIGNAL ENGINE

Adds a transparent volatility-regime synthesis layer on top of V0.6.5.

Inputs:
- ATM IV minus realized volatility
- Put skew
- Call skew / smile structure
- Heston market-vs-model residual
- Net gamma structure
- Mean model dislocation as conviction/intensity

Outputs:
- 0–100 volatility signal
- VOL EXPANSION / EXPANSION WATCH / NEUTRAL /
  COMPRESSION WATCH / VOL COMPRESSION
- Signal strength
- State metrics
- Component attribution
- Strongest volatility drivers
- Calibration confidence

This is a research/education signal engine. It does not automatically execute
trades and does not represent a probability of profit.
