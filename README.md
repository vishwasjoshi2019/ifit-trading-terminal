# IFIT Prototype V0.8.1

Indian Financial Intelligence Terminal — Terminal Architecture release.

This release turns the V0.8.0 consolidated intelligence prototype into a terminal shell with Markets, Equities, Options, Charts, Portfolio, Risk Engine and AI Intelligence workspaces.

Run on Windows:
```cmd
python -m streamlit run app.py
```

Open: http://localhost:8501

Production note: the included market feed remains simulation/proxy data until an authorized broker, NSE feed or data-vendor connection is configured.
